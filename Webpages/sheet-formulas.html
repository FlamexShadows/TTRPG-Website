Sheet Formulas

Basic Rules, updated November 26, 2026

Every number on a character sheet comes from these formulas. Round down after any division.

Statistics

ValueFormula
Stat Modifier(score − 8) ÷ 2, rounded down
Critical ChanceWits score (minimum 0)

Resources

ValueFormula
Health(level × health die average) + Fortitude modifier
Manaclass Mana + Charisma modifier (minimum 0)
Staminaclass Stamina + Fortitude modifier (minimum 0)

Defenses

ValueFormula
Armor Classworn armor's AC + Finesse modifier, up to the armor's maximum Finesse bonus
Armor Class (no armor)10 + Finesse modifier
Physical Armor5 × Fortitude modifier (minimum 0)
Magical Armor5 × Intelligence modifier (minimum 0)
EvasionFinesse modifier + class save bonus + magical bonus − penalties
Resistance (Body)Fortitude modifier + class save bonus + magical bonus − penalties
Resistance (Mind)Wits modifier + class save bonus + magical bonus − penalties
Magic armor and shieldsmagical bonus added to AC and to every save

Combat

ValueFormula
Attack BonusStrength modifier, or Finesse modifier for a Light or Ranged (Finesse) weapon when Finesse is higher, + level if proficient + magical bonus + class features − penalties
Weapon Damageweapon die + the same stat modifier used for the attack + magical bonus
Initiatived20 + Wits modifier
Speedracial speed + feature bonuses, in meters per AP
Magic weaponmagical bonus added to attack and damage, plus any Accuracy
Decisive range20, widened by 1 per level of Deadly
Spell Attacklevel + primary stat modifier + magical bonus − penalties
Spell Save DC10 + primary stat modifier + magical bonus − penalties
Maneuver Attacklevel + primary stat modifier + magical bonus − penalties
Maneuver Save DC10 + primary stat modifier + magical bonus − penalties

Skills and Gear

ValueFormula
Skillsstat modifier + skill rank
Toolsstat modifier + skill rank, if proficient
Carrying CapacityStrength score × 5 kg
Weight Carriedtotal weight of carried items
