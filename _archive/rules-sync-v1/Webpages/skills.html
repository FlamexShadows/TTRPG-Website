Skills · Saves

A skill check adds the skill's stat modifier and your skill rank. In combat, a skill check costs 3 AP unless its entry says otherwise.

Saves

Saves resist harmful effects. Each save adds a stat modifier and your class save bonus.

  • Evasion = Finesse modifier + class save bonus.
  • Resistance (Body) = Fortitude modifier + class save bonus.
  • Resistance (Mind) = Wits modifier + class save bonus.
